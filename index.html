💻 Code Examples (Aapki Website me lagane ke liye)
// 1. Generate Token over HTTPS API
async function issueQr() {
    const res = await fetch('https://your-domain.com/Qr_scanner/public/api/v1/tokens/issue', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ api_key: 'YOUR_API_KEY', ttl_minutes: 60, max_uses: 1 })
    });
    const data = await res.json();
    console.log('Generated Token:', data.data.token);
}

// 2. Real-time Push Listener over SSE
const eventSource = new EventSource('https://your-domain.com/Qr_scanner/public/developer/events');
eventSource.addEventListener('token_used', (event) => {
    const alertData = JSON.parse(event.data);
    alert(`🚨 Gate Scanned! Token: ${alertData.data.token} Status: ${alertData.data.result}`);
});
🌐 GitHub Pages par Kaise Host Karein? (Step-by-Step)
Step 1: File Copy Karein
Is HTML file (`client_template/index.html`) ki puri code copy kar lein.
Step 2: GitHub me naya Repository banayein
GitHub par qr-client-test name se public repository create karein aur index.html naam se file commit karein.
Step 3: GitHub Pages Enable karein
Repository Settings → Pages par jayein. Branch me main select karke Save karein.
Step 4: Live URL Open Karein
Aapko https://your-username.github.io/qr-client-test/ URL milega. Us URL ko open karke Server Base URL me apne live domain/IP enter karke test karein!
